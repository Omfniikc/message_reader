# message_reader

Telegram-бот, который делает самари переписки из личек, групп и каналов.

## Как это работает

Обычный Bot API не умеет читать произвольные чаты, поэтому проект состоит из двух частей:

- **Telethon (user-аккаунт)** — подключается к твоему аккаунту Telegram и по запросу вычитывает последние сообщения любого чата/канала.
- **aiogram (бот)** — интерфейс: команды, выбор чата кнопками, выдача самари.
- **LLM API (OpenAI или Anthropic)** — генерирует самари; провайдер выбирается в `.env`.

Режим работы — **on-demand**: сообщения не хранятся постоянно, при команде бот подтягивает последние N сообщений и суммирует их. Доступ — только у владельца (`OWNER_ID`).

## Установка

```bash
uv sync                      # установить зависимости
cp .env.example .env         # и заполнить значения
uv run python main.py        # первый запуск — интерактивный вход в аккаунт
```

При первом запуске Telethon попросит в терминале номер телефона и код входа;
дальше используется сохранённый `.session`-файл.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `API_ID`, `API_HASH` | ключи с [my.telegram.org](https://my.telegram.org) → API development tools |
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | твой Telegram user id (например, от [@userinfobot](https://t.me/userinfobot)) |
| `LLM_PROVIDER` | `openai` или `anthropic` |
| `LLM_API_KEY` | ключ API выбранного провайдера |
| `LLM_MODEL` | имя модели (по умолчанию `gpt-4o-mini` / `claude-sonnet-4-20250514`) |
| `DEFAULT_MESSAGE_LIMIT` / `MAX_MESSAGE_LIMIT` | сколько сообщений читать по умолчанию / максимум |
| `MAX_TRANSCRIPT_CHARS` | бюджет символов транскрипта для LLM |
| `SESSION_NAME` | имя файла сессии Telethon |

## Команды бота

- `/start`, `/help` — справка
- `/chats` — список последних диалогов, самари кнопками
- `/sum <чат> [N] [инструкция]` — самари последних N сообщений

Примеры `/sum`:

```
/sum @durov 50
/sum 123456789 200 только про дедлайны
/sum рабочая группа
```

Чат задаётся `@username`, числовым id или подстрокой названия. N по умолчанию — 100.

## Безопасность

- `.env` и `*.session` — секреты и уже в `.gitignore`, не коммить их.
- Автоматизация user-аккаунта должна быть умеренной: on-demand чтение — щадящий режим, но массовые действия могут привести к ограничению аккаунта.
